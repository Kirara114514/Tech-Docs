## 讨论摘要

以 C# .NET GC（分代+compact）为基准，对比了 UE UObject GC（反射驱动增量标记-清扫）和 Lua GC（轻量增量/分代标记-清扫）的机制。覆盖了引用链构建、写屏障、GC 集群、分代策略、内存整理、实际开发坑点等核心话题。

## 关键收获
1. 三种 GC 的"知"的程度不同：C# 全自动追踪引用，Lua 知道 Table 层面的引用，UE 只知道 UPROPERTY 显式声明的引用——这对跨语种开发者的心态转换至关重要
2. 写屏障是增量 GC 的核心难点：UE 用前置（保守），Lua 用后置（激进），C# 不需要（STW 一次性标记）
3. UE GC 的 Destroy/MarkAsGarbage 能"绕过"UPROPERTY 保活——这个状态在 C# 中没有对应概念，是 UE 新手最常见的坑
