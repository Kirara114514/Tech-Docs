## 关键收获
1. 万能抽象层与配置驱动是正交概念，不应混谈。前者是架构层面，后者是运行时行为层面。
2. 配置驱动的适用边界由两个正交维度界定：逻辑结构的可预见性 + 状态依赖的局部性。由此产生四层分类框架。
3. 好的抽象是「现在时」的（描述已有实现的共性），坏的抽象是「将来时」的（预测未来可能的实现）。
4. UI 架构的工业化方案对比中，所有方案的通病是动画和时序编排——需要独立的「UI 过渡编排层」。
5. 「改动代码 = 失败」的直觉有四重来源：学校教育、开源叙事、小项目经验迁移、成本误估。
6. 从小项目到工业化的核心转变不是学新东西，是放弃旧习惯：放弃全能幻觉、放弃优雅审美、放弃改动恐惧。
